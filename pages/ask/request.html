처리 절차

1. 이메일 접수

요청 내용을 확인한 뒤 접수 여부와 추가 확인 필요 사항을 회신합니다.

2. 자료 확인

요청 내용과 관련 자료를 검토하고 필요한 경우 추가 자료를 요청합니다.

3. 검토 결과 안내

감사 진행 여부, 확인 결과, 후속 절차를 가능한 범위에서 안내합니다.
